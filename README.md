# speedtest


# Описание
Скрипт измеряет скорость загрузки данных с урла.

Скрипт принимает адрес (аргумент `-u\--url`), 
запускает последовательно N запросов (определяется аргументом `-r\--retries`)
вычисляет среднее время запроса, средний размер и среднюю скорость, 
а так же общее количество времени и общий размер данных

# Использование:
```(bash)
python speedtest.py -u <url:str> -r <retries:int> -c <chunk_size:[KB, MB, GB, KBI, MBI, GBI]> -d <delay:float> -j <jitter:float>
```
## Справка по аргументам:
```(bash)
python speedtest.py -h
```
